  • 登录方式：GitHub OAuth Authorization Code + PKCE
  • 数据存储：浏览器 localStorage 本地持久化
  • 当前状态：已接入纯前端 PKCE 结构与回调页

Setup Guide

你要填的关键值

当前是配置引导态，填完后这里会自动切成“已配置”状态摘要。
  1. GitHub -> `Settings` -> `Developer settings` -> `OAuth Apps`
  2. 创建一个 OAuth App，拿到 `Client ID`
  3. 把 `Client ID` 填进 `static/js/github-config.js`
  4. 回调地址填当前站点的 `github-callback.html`
  5. 前端只填 `client_id`，不要把 `client_secret` 放进页面
